- `yan-nan-fei.html` — 《雁南飞》

## Publish with GitHub Pages
1. Create a new **public** GitHub repository, e.g. `portfolio-writing`.
2. Upload all three files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save and wait for GitHub Pages to publish.

Your site will typically be available at:
`https://YOUR-USERNAME.github.io/portfolio-writing/`

Direct article links:
- `https://YOUR-USERNAME.github.io/portfolio-writing/pingjiang.html`
- `https://YOUR-USERNAME.github.io/portfolio-writing/yan-nan-fei.html`
